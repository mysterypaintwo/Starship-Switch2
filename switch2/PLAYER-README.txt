STARSHIP FOR SWITCH 2 - v1.1
============================

Unofficial port of Starship (Star Fox 64) for a Switch 2 that can run homebrew.


WHAT'S NEW IN v1.1
- A full-screen menu with search, sized for the Switch 2 screen.
- English, Japanese and European (Lylat Wars) voices in one Voices menu.
- Much less stutter, with a loading screen and shaders prepared during boot.
- Audio fixes.
- Fixed crashes when closing the game and when installing JP/EU audio.
- A clear message if game files are missing.
See CHANGELOG.md for the full list.


INSTALL
1. Copy the "switch" folder to the root of your SD card, replacing old files.

2. Copy your own US Star Fox 64 ROM (.z64, .n64 or .v64) to /switch/starship/.
   Already have sf64.o2r? Keep it instead. GAME-DATA.md has the details.

3. Start "HarbourMasters - Starship" from the homebrew menu. On first launch,
   answer Yes to make the game data. This takes a few minutes.


VOICES (OPTIONAL)
English is already in your US game. Japanese needs the JP ROM, and European
(Lylat Wars) needs the EU ROM.

1. Copy the ROMs to /switch/starship/. You need 64 MB free on the SD card.
2. Open the menu with -, then Settings > Language > Install JP/EU Audio.
3. Pick the language under Voices, then restart Starship.


CONTROLS
  Switch 2 button     Game button
  B                   Fire
  Y                   Bomb
  ZL                  Boost
  ZR                  Brake
  L / R               Roll
  X                   First-person view (C-Up)
  A                   Answer calls (C-Right)
  Right stick         C buttons
  -                   Open the menu


REPORTING A BUG
Say what you were doing, and include the /switch/starship/logs/ folder.
Do not share your ROM or any sf64 .o2r file.
